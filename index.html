Sobre Mi

Desarrollador de software enfocado en la creación de aplicaciones web y de escritorio eficientes. Con dominio en lenguajes como C# y Java, me apasiona conectar arquitecturas robustas en el backend con interfaces de usuario limpias, responsivas y atractivas.

Código Limpio

Resolución

Mis Proyectos

NutriLife

NutriLife es una innovadora herramienta que facilita a los nutricionistas el seguimiento de la salud de sus pacientes. Permite calcular el IMC, registrar información vital y ofrece visualizaciones claras.

Proyecto Molaris

Plataforma web desarrollada en Laravel y Tailwind CSS para la gestión integral de clínicas dentales. Permite la administración de pacientes, agendamiento de citas con control de colisiones y avisos.

El Café del Negro José

El Café del Negro José es un sitio web dedicado a brindar una experiencia única y acogedora para los amantes del café. Diseñada exclusivamente utilizando tecnologías de frontend.

Fragaria Perfumes

Fragaria Perfumes es una aplicación web full-stack desarrollada para la gestión y visualización de un catálogo exclusivo de perfumería prémium con arquitectura MVC.

Patitas y Huellas

Este proyecto es una aplicación web desarrollada con Django que permite gestionar información sobre mascotas y sus dueños. Incluye funciones para registrar, editar y eliminar registros.

Nube IPVG

Lideré el diseño técnico de una infraestructura elástica en AWS para erradicar los colapsos de la intranet institucional. Coordiné la puesta a punto de un clúster de bases de datos de 3 nodos.

Parkr App

Parkr es una aplicación de parquímetros desarrollada en Android, diseñada para facilitar el proceso de pago y gestión del estacionamiento de forma transparente y fluida.

Wilson XD

Wilson XD es un sistema operativo web interactivo. Simula una experiencia de escritorio retro donde cada usuario cuenta con un entorno aislado y persistente con descargas y simulación BSOD.

MotorGet

Aplicación web desarrollada con Python y Django que permite gestionar automóviles de manera eficiente. Funcionalidades para agregar, editar, eliminar y visualizar vehículos.

EduFácil

Aplicación web diseñada para simplificar la administración de datos escolares. Resuelve la complejidad académica controlando el ciclo completo de registros de alumnos.

Nutrilife IA Android

El objetivo de NutriLife IA es ayudar a los usuarios a mejorar su salud mediante una herramienta gratuita y accesible, promoviendo hábitos saludables con Inteligencia Artificial.

Portafolio Web

Portafolio profesional concebido para exhibir mi trayectoria. Desarrollado combinando Bootstrap 5 con un diseño de UI personalizado en CSS3 y lógica de control en JavaScript.
